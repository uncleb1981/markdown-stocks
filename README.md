# The Reset

One brutal quarter — cleared on purpose. Sometimes a company doesn't just have a bad quarter, it chooses one: a new CEO writes off everything undesirable in a single shot so next year looks better by comparison, and the board resets expectations hard, all at once. The Reset looks for the fingerprints of that: a real, recent, unusually large earnings miss (or a swing straight into a loss) in a stock down 20%+ over the past month, RSI under 45, market cap over $1 billion, excluding banks/pharma/biotech (their swings are usually regulatory or macro, not a deliberate reset). Whatever clears that gets ranked by a 0-100 Reset Score weighted toward the size of the miss (45%), how hard the stock fell (25%), how oversold the RSI is (20%), and a best-effort bonus (10%) for a confirmed, recently timed leadership change found via web search — a card says so plainly when that search comes up empty. Some days nothing clears the bar; that's the screen working as intended, not a bug.

Swipe (or tap Pass/Back) through each day's picks. Backed names go to a local Boardroom list. Each card also shows its next earnings date and the RSI level that would need to clear before the pick stops counting as oversold — objective checkpoints instead of a suggested holding period.

**Informational only — not investment advice.** See the in-app FAQ for the full methodology.
